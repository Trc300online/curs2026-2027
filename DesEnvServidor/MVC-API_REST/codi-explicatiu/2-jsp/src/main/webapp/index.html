JSP, EL i JSTL

DWES · Jakarta EE, passa 2. Els enllaços van en l'ordre dels blocs de les diapositives.

1 · Què és una JSP

  • /hola.jsp: la primera JSP. Canviau-hi un text, desau i recarregau: no cal compilar.
  • /classica.jsp?n=5: les etiquetes clàssiques, amb codi Java dins la pàgina.

2 · Del Servlet a la JSP

  • /benvinguda?nom=Aina: el Servlet decideix i la JSP pinta.
  • /WEB-INF/vistes/benvinguda.jsp: i si intentam obrir la vista directament?
  • /anar?com=forward i /anar?com=redirect: mirau la barra d'adreces i F12 › Xarxa.

3 · Expression Language

  • /el?nom=Aina&nom=Pau: cada expressió amb el seu resultat.

4 · JSTL

  • /tallers: c:forEach, c:choose, c:url, fmt:formatNumber.
  • /salutacio?nom=<script>…: c:out escapa, ${…} no.
  • /inscripcio: el formulari de la passa 1, sense cap println. Enviau-lo amb errors.

5 · Organitzar les vistes

  • /taller?id=noexisteix, /noexisteix: la nostra pàgina d'error per al 404.
  • /falla: la mateixa pàgina per al 500.
