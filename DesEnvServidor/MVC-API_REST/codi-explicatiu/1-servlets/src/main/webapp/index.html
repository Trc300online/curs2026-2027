Primers Servlets

DWES · Jakarta EE, passa 1. Cada enllaç fa una petició a un Servlet.

2 · El primer Servlet

  • /hola: HolaServlet. Recarregau-lo: l'hora canvia.
  • /peticio, /peticio/cursos/7?nom=Aina&nom=Pau&idioma=en: tot el que porta una petició.
  • HolaServlet només té doGet: què torna Tomcat?

3 · Rebre dades

  • /salutacio, ?nom=Aina, ?nom=Aina&idioma=en&vegades=3
  • /salutacio?vegades=tres: i si el número no és un número?
  • Formulari d'inscripció (POST a /inscripcio)
  • /inscripcio escrit a la barra: és un GET

4 · Respondre

  • /hora, ?format=text, ?format=json, ?format=xml
  • /enllac/tomcat, /enllac/jakarta, /enllac/mdn, /enllac/noexisteix
  • /noexisteix: una URL que no té cap Servlet

5 · Com viu un Servlet

  • /comptador: obriu-lo també des d'un altre navegador i mirau la consola de Tomcat.
